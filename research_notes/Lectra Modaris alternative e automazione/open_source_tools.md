# Free / open-source tools for pattern making (cartamodelli), grading and marker making as alternatives or complements to Lectra Modaris (status as of October 2026)

Research method note: the GitHub API and many project sites were blocked by this environment's network proxy (forum.seamly.io, smart-pattern.com.ua, freesewing.eu, codeberg.org, ezdxf.readthedocs.io, wikipedia.org, help.grafis.de and others). Facts were collected from GitHub pages that could be fetched, PyPI/npm registry metadata (queried directly), and search-engine snippets of the blocked pages. Findings that rest only on a search snippet are marked "(snippet)". The report writer should treat those as reliable in substance, but the exact wording and dates were not checked against the full page.

## Q1. What each tool can do: features, maturity, OS support, how easy it is to learn, Italian support and latest release

### Takeaway
The one mature, actively developed, fully free parametric pattern CAD in 2026 is **Seamly2D**. It ships weekly releases through September 2026, runs on Windows, macOS and Linux, has an Italian manual and translation, and handles formulas, measurement files, multisize grading, seam allowance, notches and a simple layout. **Valentina**, the project Seamly2D was forked from, is still developed and released 1.1.0 in June 2026, but since 1.0 (mid-2025) its binaries need a **paid subscription**; 0.7.53 is the last free build. **FreeSewing** (MIT, JavaScript, v4.10.2 in September 2026) is very active but is a made-to-measure library for people who write code, not a CAD. **GarmentCode/pygarment** and **Sewformer** are research tools. For 3D, **Blender 5.2 LTS** is free, but useful garment workflows depend on add-ons, many of them paid. For nesting, **deepnest-next** (MIT) is the maintained free option. **SVGnest** and the original **Deepnest** are legacy projects.

**FreeSewing, a JavaScript made-to-measure pattern library and website**
- npm `@freesewing/core`: latest **4.10.2 published 2026-09-13**, license **MIT**, with a "next" tag at 4.0.1-rc.1. Queried directly from the npm registry. — [npm registry @freesewing/core](https://registry.npmjs.org/@freesewing/core)

(snippets) — [FreeSewing blog: us-and-eu](https://freesewing.eu/blog/us-and-eu); [FreeSewing forum: GitHub→Codeberg migration](https://forum.freesewing.eu/t/updates-on-the-github-to-codeberg-migration/60)

**GarmentCode / pygarment (ETH Zurich, Maria Korosteleva et al.), research-grade parametric garment programming**
- A Python framework for parametric sewing patterns. Base types are Edge, Panel, Component and Interface. It includes a GUI configurator, body-measurement integration (the GarmentMeasurements project), physics simulation with NVIDIA Warp, and outputs **SVG, PNG and a JSON pattern spec**. MIT license, 1,512 commits; the online configurator was working as of June 2025. The companion dataset GarmentCodeData (v2, Sep 2024) was accepted at ECCV. The README says nothing about seam allowance, notches or industrial grading. — [GarmentCode GitHub](https://github.com/maria-korosteleva/GarmentCode)
- PyPI `pygarment` latest is **2.0.2, uploaded 2025-04-18**, MIT: "A modular programming framework for designing parametric sewing patterns". Queried directly. — [PyPI pygarment](https://pypi.org/project/pygarment/)

**Sewformer (Sea AI Lab), image to sewing pattern, research only**
- Reconstructs sewing patterns from one photo with deep learning. Published in ACM TOG (SIGGRAPH Asia 2023). Uses PyTorch and needs a GPU. No license file is specified, and the repo has only 28 commits. Output patterns are meant to be simulated in Autodesk Maya. Of little practical use to a fashion student. — [Sewformer GitHub](https://github.com/sail-sg/sewformer)

**Inkscape + sewing extensions, and 2D CAD (LibreCAD / QCAD / FreeCAD)**
- Inkscape can add seam allowance with Path → Outset, setting the outset step in Preferences → Steps. The value is in px and must be converted (for example 56.25 px = 5/8″ at 90 dpi). — [Projector Sewing: seam allowance in Inkscape](https://projectorsewing.com/seam-allowance-inkscape/); [Grow Your Own Clothes: tips for drafting in Inkscape](https://growyourownclothes.com/2014/10/30/tips-for-pattern-drafting-with-inkscape/)
- **Dopplemaker**: an Inkscape extension for graded or custom-fit patterns, with formula helpers, standard women's/children's measurements and ready blocks (bodice, dress, skirt, leggings). GPL-3.0, only 16 commits and 10 stars, so maintenance is minimal. Its wiki covers seam allowances and notches. — [Dopplemaker GitHub](https://github.com/lisjump/dopplemaker); [Dopplemaker wiki: Adding Seam Allowances](https://github.com/lisjump/dopplemaker/wiki/Adding-Seam-Allowances)
- **Unroll Path**: an Inkscape extension that turns a curved path into a straight strip with optional width and offset, which is useful for bindings and seam-allowance strips. — [inkscape-unroll-to-straight-extension](https://github.com/pricklygorse/inkscape-unroll-to-straight-extension); [MYOG Tutorials: Unroll Path](https://www.myogtutorials.com/inkscape-extension-for-pattern-making-unroll-path/)
- Other small projects: "patterns", an Inkscape extension (status not verified), and "PatternBridge", which reads sewing patterns into structured geometry (boundary, grain line, notches, darts), grades them and writes SVG, tiled PDF or JSON (maturity not verified). — [kirchner/patterns](https://github.com/kirchner/patterns); [PatternBridge](https://github.com/JinnZ2/PatternBridge)
- **LibreCAD** stable 2.2.1.4 (3 Mar 2026). **QCAD** stable 3.32.3.4 (17 Jul 2025). **FreeCAD 1.1** released 24/25 Mar 2026. (snippets) — [LibreCAD (Wikipedia)](https://en.wikipedia.org/wiki/LibreCAD); [QCAD (Wikipedia)](https://en.wikipedia.org/wiki/QCAD); [FreeCAD 1.1 released – FreeCAD News](https://blog.freecad.org/2026/03/25/freecad-version-1-1-released/)
- Generic CAD DXF is **not** accepted by Modaris. In Modaris it is not possible to import regular DXF files from AutoCAD (error "not possible to import", related to layers), and "DXF AAMA and DXF ASTM are named both as filename.dxf, but the content is a little bit different". (snippet) — [Autodesk forum: AutoCAD export to DXF AAMA or ASTM](https://forums.autodesk.com/t5/autocad-forum/autocad-export-to-dxf-aama-or-dxf-astm/td-p/7014285); see also [McNeel forum: export file for Modaris, need DXF AAMA or ASTM](https://discourse.mcneel.com/t/export-file-for-modaris-lectra-need-dxf-aama-or-astm/9708)

**Blender for 3D cloth (as a free alternative to CLO3D)**

(snippet) — [Garment Tool on Gumroad](https://bartoszstyperek.gumroad.com/l/GarmentTool?ref=311); [Garment Tool docs](https://joseconseco.github.io/GarmentToolDocs/)
- **Simply Cloth** (paid, Superhive marketplace) offers a library of 200+ sewing patterns and accessories inside its own simulation environment. **Procedural Cloth Sewing Toolbox** (Blender 4.2+, paid) adds stitching details with Geometry/shader nodes, "mimicking" Marvelous Designer/CLO features. Prices not verified. — [Simply Cloth – Superhive](https://superhivemarket.com/products/simply-cloth); [Procedural Cloth Sewing Toolbox – Superhive](https://superhivemarket.com/products/proceduralsewingtoolbox)

**Open-source and free nesting (marker making)**
- **deepnest-next**: a community fork of Deepnest/SVGnest "for laser cutters, plasma cutters and other CNC machines", with the speed-critical nesting engine written in C. MIT, 198 stars, 40 forks, 323 commits. SVG is native; DXF works "through conversion" today, and native DXF is on the roadmap along with Rust performance work, presets, CSV/JSON project loading and cloud nesting. — [deepnest-next GitHub](https://github.com/deepnest-next/deepnest)
- deepnest-next releases: hotfix v1.5.1 on 25 Mar 2025, made necessary because the original deepnest.io converter API was failing. v1.5.2–1.5.4 came in April 2025, v1.5.5 on 9 May 2025, and v1.5.6 in May 2025 with signed macOS/Linux/Windows builds. (snippets) — [Patreon: hotfix v1.5.1](https://www.patreon.com/deepnest_next/posts/hotfix-release-5-125155643); [deepnest-next releases](https://github.com/deepnest-next/deepnest/releases)
- A vendor (Lapas, a competing nesting product) calls deepnest-next true-shape GA nesting with DXF/SVG input and output, "the best free offline nesting option", suited to hobbyists and low-volume shops. That conflicts slightly with the README's "DXF through conversion". (snippet) — [Lapas: Free nesting software in 2026](https://lapas.io/blog/free-nesting-software/)
- **Original Deepnest** (Jack000): 1.2k stars, 324 forks, 183 open issues, desktop app with DXF support and common-line merging. Its online DXF converter broke in 2025 (see above), which is a sign of an abandoned upstream. — [Jack000/Deepnest](https://github.com/Jack000/Deepnest)
- **SVGnest** (Jack000): browser-based, MIT, 2.6k stars, about 100 commits. Places parts with No-Fit-Polygons and orders and rotates them with a genetic algorithm (first-fit-decreasing). Settings include spacing, curve tolerance, number of rotations, population and mutation rate, and part-in-part placement. NFP edge cases remain on its to-do list. — [Jack000/SVGnest](https://github.com/Jack000/SVGnest)
- **PowerNest** (Almacam) is **not** open source. It is a commercial nesting library (DLL or web service) "originally developed by applied mathematics researchers to optimize material use in textile cutting". Almacam offers a **free online demonstrator** that imports DXF. Its Nest&Cut web app covers textiles. (snippets) — [PowerNest – worldwide nesting leader](https://powernestlib.com/powernest-worldwide-nesting-leader/); [PowerNest free automatic nesting demo](https://powernestlib.com/automatic-nesting-demo-app/); [Alma Nest&Cut](https://almacam.com/nest-and-cut-web-based-application-for-automatic-nesting/)

**Libraries for handling DXF / DXF-AAMA / ASTM in code**
- **ezdxf** (Python): latest **1.4.4, uploaded 2026-05-14**, requires Python ≥3.10. Queried directly from PyPI. — [PyPI ezdxf](https://pypi.org/project/ezdxf/)
- ezdxf ships an **ASTM-D6673-10 exporter add-on** (`gerber_D6673`) that writes the special DXF R12 files Gerber AccuMark expects. It was created in Dec 2022 after users' ezdxf files were rejected by AccuMark. Maintainer mozman wrote: "Gerber Technology software does not conform to the ASTM D6673-10 standard, which requires a valid DXF format". The add-on targets Gerber only; Lectra and CLO were not discussed. — [ezdxf docs: ASTM-D6673-10 Exporter](https://ezdxf.readthedocs.io/en/stable/addons/gerber_D6673.html); [ezdxf Discussion #789](https://github.com/mozman/ezdxf/discussions/789)
- A snippet mentions an ezdxf "epattern" add-on in an `astm_d6673` branch that can *load* and export ASTM D6673. Its status is not verified. (snippet) — [ezdxf Discussion #789](https://github.com/mozman/ezdxf/discussions/789)
- **astm-parser** (ksons, TypeScript/Node 22): parses ASTM/AAMA DXF from Gerber AccuMark and CLO into the "Open Pattern Format" (OPF), a JSON format for graded patterns "designed to replace DXF/ASTM", validated with JSON Schema in CI. It extracts grading across sizes; notch types (V/slit, T, castle, check, U); grain and mirror lines; drill holes; sew lines; and internal cutouts. A CLI converts to JSON, SVG and images. License not stated. — [ksons/astm-parser](https://github.com/ksons/astm-parser)
- **Patro** (Fabrice Salvaire, Python, docs v0.3.0) documents the DXF-ASTM file format. Current activity not verified. — [Patro: DXF ASTM file format](https://fabricesalvaire.github.io/Patro/resources/file-format/dxf-astm.html)
- **JBlockCreator**: an open-source Java framework for automated made-to-measure block drafting (academic, 2018). — [ScienceDirect: JBlockCreator](https://www.sciencedirect.com/science/article/pii/S2352711018302528)
- Standard status: ASTM D6673-10 ("Sewn Products Pattern Data Interchange – Data Format") is listed as **withdrawn in 2019**. It used DXF for pattern pieces and an ASCII file for grade-rule tables. — [iTeh: ASTM D6673-10 (Withdrawn 2019)](https://standards.iteh.ai/catalog/standards/astm/3ea6d7eb-457d-4601-8b2a-568fe262a910/astm-d6673-10)

### Inferences
- Seamly2D is the right "primary" tool for an Italian student. It is free with no subscription, under very active development (weekly builds in 2026), cross-platform, and has an Italian manual and translation. Its concepts (points, formulas, measurement variables, pieces/details, seam allowance, notches) map well onto how Modaris students already think.
- Valentina is now "open source but paid binaries": GPL code, with 1.x binaries behind a subscription. A student can use the free 0.7.53 legacy version, but should know it lacks the AAMA/ASTM fixes made in 1.x. Compiling 1.x from GPL source is legally allowed but too technical for a non-expert. The subscription price was not found (see Gaps).
- Seamly2D and Valentina share a common ancestry: Seamly2D's GitHub issues, such as #59, carry dates going back to 2015 and were re-opened in 2017. Their file formats have since diverged (Seamly's .smms vs Valentina's dimension-based multisize files), so moving files between them is getting harder. This rests on general knowledge plus the issue dates; no fetched page described the 2017 split.
- FreeSewing suits a student who wants quick made-to-measure base blocks or is curious about coding patterns. It is not a CAD for drafting from scratch with a mouse, and no source showed DXF-AAMA export (see Gaps).
- GarmentCode/pygarment and Sewformer are research projects. They are worth knowing for the "automation / AI" angle, but they lack seam allowance, notches and grading, so they are not usable for coursework.
- Inkscape is best used as a finishing tool: overlaying sizes, labels, tiling for home printing, and tidying SVG exports from Seamly2D or FreeSewing. It is not a parametric CAD. The Inkscape sewing extensions are small, lightly maintained hobby projects.
- LibreCAD, QCAD and FreeCAD are actively maintained but are generic CAD. They make plain DXF, which Modaris rejects, and they have no apparel concepts (grade rules, notches as objects, piece blocks).

- Whether Seamly2D's built-in layout is true-shape nesting or a simple greedy/bounding-box placement could not be confirmed from primary docs.

## Q2. Interoperability: can these tools exchange DXF-AAMA/ASTM files with Lectra Modaris, and what goes wrong (layers, grade rules, notches)?

### Takeaway
Only **Seamly2D** and **Valentina** produce apparel-flavoured DXF (AAMA, plus ASTM in Valentina 1.x). Even these exports carry **one size of geometry only, with no grade rules**. Seamly2D users report that Modaris imports just the grainlines, though an older workflow ("DXF 2013 AAMA" opened in Modaris with AAMA import) once worked. Valentina 1.x focused its AAMA/ASTM fixes on **CLO3D**, not Lectra. Nothing open source **imports** a Modaris AAMA/ASTM file as an editable parametric pattern. Programmers can read and write AAMA/ASTM with ezdxf or astm-parser. Expect a one-way, single-size, test-every-time workflow.

### Cited Findings
- A Seamly2D user exporting for Lectra reported getting "only the grainlines in Lectra after export". The same user had earlier exported "as 2013 DXF files and imported them into Lectra Modaris as AAMA format" with success. (snippet; thread not fetchable) — [Seamly forum: Exporting dxf pattern to be imported into Lectra](https://forum.seamly.io/t/exporting-dxf-pattern-to-be-imported-into-lectra/17010)
- According to the forum, the Seamly team "is currently working on a new layout feature that correctly produces DXF-ASTM files that are CLO3D compatible" and "would like to do the same for Lectra if users share Lectra-compatible DXF files". (snippet; it is not certain which forum thread this came from, and no date was given) — [Seamly forum: Lectra thread](https://forum.seamly.io/t/exporting-dxf-pattern-to-be-imported-into-lectra/17010); [Seamly forum: Export problems Seamly2D → CLO3D](https://forum.seamly.io/t/export-problems-seamly2d-clo3d/11740)
- A French-language forum thread asks which DXF to use for Modaris and whether Seamly2D can import DXF. Its content could not be fetched. — [Seamly forum: "Qu'elle DXF pour modaris et peut on importer un DXF"](https://forum.seamly.io/t/quelle-dxf-pour-modaris-et-peut-on-importer-un-dxf/5273)
- Seamly2D GitHub issue **#59, "Replace current DXF-AAMA exports with DXF-ASTM"**, is still **open**: first reported 8 Oct 2015, re-filed 22 Nov 2017, unassigned, with no linked PR. — [Seamly2D issue #59](https://github.com/FashionFreedom/Seamly2D/issues/59)
- Seamly2D issue #240 (June 2020): flat DXF R10 export produced corrupted "trash strings" in text, and AAMA export worked fine. The workaround is "Export text as paths" in the layout dialog. — [Seamly2D issue #240](https://github.com/FashionFreedom/Seamly2D/issues/240)
- Seamly2D cannot export all sizes in one file (Nov 2024); each size must be exported separately. — [FashionFreedom Discussion #1199](https://github.com/orgs/FashionFreedom/discussions/1199)
- Valentina 1.0 "improved DXF AAMA/ASTM compatibility for smooth integration with Clo3D" and fixed annotation and label font sizes on AAMA/ASTM export. (snippet) — [Valentina 1.0.0 page](https://smart-pattern.com.ua/en/private/valentina/version/1.0.0/); [dismine/valentina releases](https://github.com/dismine/valentina/releases)
- Graded AAMA works like this: "the contour of the base size is normally written into the .DXF file and the graded sizes are written as a grade rule table into a separate .RUL file". A graded pattern "must come with a .RUL file … without both components it will not work". The .DXF and .RUL with the same name must travel together. (snippets) — [GRAFIS help: Import of grade rule patterns](https://help.grafis.de/en-gb/Content/ExportIImport/Import_von_Sprungwertschnitten.htm); [Garmenta Apparel: digital files your patternmaker will provide](https://www.garmentaapparel.com/blog/all-about-the-digital-files-that-your-patternmaker-will-provide)
- "DXF interoperability with apparel software is an industry-wide problem; the definition of the AAMA format is not unambiguous and is interpreted differently by different CAD suppliers." (snippet, GRAFIS help) — [GRAFIS help: Export formats and their characteristics](https://help.grafis.de/en-gb/Content/ExportIImport/Exportformate_und_deren_Besonderheiten.htm)
- AAMA layer conventions: perimeter cut line on layer 1, notches on layer 4, grain line on layer 7, text on layer 19. Each pattern feature (cut line, sew line, internal lines, grainline, notches, drill holes, turn points, annotation) lives on a designated numbered layer. Typical failures: "notches may vanish, a grainline may import as an ordinary line, or seam allowance may be fused to the cut line so the piece looks correct but grades wrong". Units matter (mm vs inch). (snippets) — [Autodesk forum thread](https://forums.autodesk.com/t5/autocad-forum/autocad-export-to-dxf-aama-or-dxf-astm/td-p/7014285); [Minerva Patterns: DXF AAMA vs DXF ASTM](https://minervapatterns.com/blog/dxf-aama-vs-dxf-astm); [MPattern: Export CAD patterns to DXF AAMA/ASTM](https://www.mpattern.app/en/blog/exportar-patrones-cad-formato-dxf-aama-astm-guia-completa)
- Issue #59 explains why AAMA matters: plain "DXF does not contain scale or units, nor usually any method of reliably describing what needs to be cut, drawn, drilled, notched". The ASTM variant uses distinct layers for corner (turn) points versus curve polyline points. — [Seamly2D issue #59](https://github.com/FashionFreedom/Seamly2D/issues/59); [search snippet referencing issue #59](https://github.com/FashionFreedom/Seamly2D/issues/59)
- Modaris rejects plain AutoCAD DXF ("not possible to import", layer-related). — [Autodesk forum](https://forums.autodesk.com/t5/autocad-forum/autocad-export-to-dxf-aama-or-dxf-astm/td-p/7014285)
- Lectra has a tutorial on importing AAMA or ASTM DXF into Modaris (video, Spanish). — [YouTube: "015- Import an AAMA or ASTM DXF file on Lectra Modaris"](https://m.youtube.com/watch?v=WNrRZpKxK4M&vl=en)
- Programmatic AAMA/ASTM support: ezdxf has a Gerber-targeted ASTM-D6673 exporter, and mozman says Gerber's parser itself breaks the standard. astm-parser reads Gerber/CLO ASTM files, including grading and notches, into JSON. — [ezdxf Discussion #789](https://github.com/mozman/ezdxf/discussions/789); [ksons/astm-parser](https://github.com/ksons/astm-parser)
- Tailornova (commercial) claims DXF-AAMA export (per aggregators). — [Capterra: Tailornova](https://www.capterra.com/p/179815/Tailornova/)
- deepnest-next reads and writes SVG, with DXF via conversion. It has no concept of AAMA piece blocks, grain or annotation layers. — [deepnest-next GitHub](https://github.com/deepnest-next/deepnest)

### Inferences
- **Home tool → Modaris**: realistically possible for **single-size** pieces from Seamly2D or Valentina via DXF-AAMA. Grading will **not** come through as Lectra grade rules. The student would have to re-grade in Modaris, or import each size as a separate piece. Each file must be checked after import for notches (layer 4), grain line (layer 7), seam allowance vs. cut line, piece names and units.
- **Modaris → home tool**: no open-source pattern CAD is documented as able to import an AAMA/ASTM file as an editable pattern. Seamly2D and Valentina are parametric and draft from points and formulas, so an imported DXF would at best be a background trace (not confirmed). For viewing or inspecting Modaris exports at home, astm-parser (JSON/SVG output) or ezdxf scripts are the practical routes, along with CLO3D and other commercial viewers.
- **Seamly2D → CLO3D** gets more developer attention than Seamly2D → Lectra. The developers have explicitly asked for Lectra-compatible sample files, which the student or university could contribute.
- Because the ASTM D6673 standard was withdrawn in 2019 and vendors read AAMA differently, even commercial-to-commercial exchange is fragile. Open-source tools add one more layer of uncertainty.
- Recommended practice is to keep the "master" pattern in Modaris for coursework, use home tools for practice and drafting logic, and always round-trip test with a simple piece (a rectangle with notches, grain line, drill hole and label) before relying on any transfer.

### Gaps
- No primary-source, step-by-step confirmation was found, for 2025–2026 versions, of which exact Seamly2D or Valentina export settings (DXF version, AAMA vs ASTM, units, "text as paths") import cleanly into a specific Modaris version (V8/V8R2/V9 etc.).
- It was not verified whether Valentina 1.x can write a **.RUL** grade-rule file next to its AAMA DXF, which would carry grading into Modaris.
- I could not confirm whether Seamly2D or Valentina can import a DXF/AAMA file (as a pattern or as a background image).
- No reports were found of FreeSewing, GarmentCode or Inkscape output being imported into Modaris.

## Q3. Realistic limits compared with Modaris (and Diamino): which professional functions are missing?

### Takeaway
Free tools cover **drafting, measurement-driven made-to-measure and basic multisize work** well, and for learning purposes Seamly2D comes close to Modaris on 2D construction. They fall short on **industrial grading** (grade rules per point and graded-nest export with .RUL), **reliable two-way exchange** with Lectra, and **production marker making**. Diamino-class features (fabric width and grain/nap constraints, stripe and plaid matching, size-ratio runs, buffers, consumption and costing, optimiser) have no open-source equal. deepnest-next and SVGnest are CNC/laser nesting engines with only rotation-count controls. For 3D, Blender plus add-ons is far from CLO3D: no native pattern-to-garment pipeline with real fabric property libraries.

### Cited Findings
- Seamly2D has no real nesting function, and "for industrial-level nesting, users need to export to other CAD software". (snippet) — [Minerva Patterns: Seamly2D practical look](https://minervapatterns.com/blog/seamly2d-and-open-source-pattern-cad-a-practical-look)
- Seamly2D cannot output graded nests (all sizes in one file) and requires external vector software for that. — [FashionFreedom Discussion #1199](https://github.com/orgs/FashionFreedom/discussions/1199)
- The open DXF-ASTM issue in Seamly2D dates back to 2015/2017. — [Seamly2D issue #59](https://github.com/FashionFreedom/Seamly2D/issues/59)
- What Diamino does: it places pieces "according to size runs, fabric widths, grain and nap, matching rules for stripes and plaids, buffer allowances, and exclusion zones", runs interactive or fully automatic nesting, batch-processes size assortments, gives consumption and cost estimates, and has an Optimizer for both interactive and automatic markers. (snippets; partly from software-download aggregator descriptions, so treat as an indicative feature list) — [Lectra press release: Diamino V5R4](https://www.lectra.com/sites/default/files/lectra/press_detail/Diamino_V5R4_EN_tcm31-159343.pdf); [CIMdata: Lectra launches newest Diamino](https://www.cimdata.com/newsletter/2008/45/02/45.02.15.htm); [Software Informer: Lectra Diamino](https://lectra-diamino.software.informer.com/)
- SVGnest/Deepnest optimisation settings are spacing, curve tolerance, number of allowed rotations, GA population and mutation rate, and part-in-part placement. They are built for laser/CNC, with no textile-specific constraints. — [Jack000/SVGnest](https://github.com/Jack000/SVGnest); [deepnest-next GitHub](https://github.com/deepnest-next/deepnest)
- PowerNest, a high-quality engine "originally developed … to optimize material use in textile cutting", is commercial. Only a free online demo is offered. — [PowerNest](https://powernestlib.com/powernest-worldwide-nesting-leader/); [PowerNest demo](https://powernestlib.com/automatic-nesting-demo-app/)
- GarmentCode makes parametric patterns with simulation but has no documented seam allowance, notches or grading for production. — [GarmentCode GitHub](https://github.com/maria-korosteleva/GarmentCode)
- Blender's cloth sim uses generic sewing springs. Garment-specific pattern workflows need add-ons (Garment Tool $54, Simply Cloth, Procedural Sewing Toolbox), and the new Geometry-Nodes cloth physics in 5.2 is labelled experimental. — [Blender manual: Cloth Shape](https://docs.blender.org/manual/en/latest/physics/cloth/settings/shape.html); [Blender 5.2 LTS](https://www.blender.org/download/releases/5-2/); [Garment Tool](https://bartoszstyperek.gumroad.com/l/GarmentTool?ref=311)
- Seamly2D's 2026 release notes are mostly UI and bug-fix work (groups, history dialog, move/rotation tool fixes), not new production or interoperability features. — [Seamly2D releases](https://github.com/FashionFreedom/Seamly2D/releases)

### Inferences
- Missing compared with Modaris or Lectra suites. This list is based on the findings above plus general knowledge of Modaris. Modaris-side features should be cross-checked with the Lectra-focused research notes:
  1. **Grading by grade rules** on individual points, with editable grade tables, nest views and .RUL export. Seamly2D and Valentina grade only through measurement tables and formulas. That is powerful and arguably more "intelligent", but it is not the industry grade-rule paradigm, and it cannot be exported as one.
  2. **Reliable AAMA/ASTM round-trip with Lectra, Gerber and Optitex**, including import of third-party graded files.
  3. **Marker making / CAM**: Diamino-style constraints (grain/nap, stripes and plaids, fabric width, size-ratio bundles, buffers, efficiency and consumption reporting), plotter and cutter output (HPGL/ISO cutter formats), and links to cut-order planning and PLM.
  4. **Integrated 3D** (Modaris 3D or a CLO link) with physical fabric parameters measured from real fabrics.
  5. **Industrial-scale productivity**: piece libraries, style management, digitiser support, enterprise file management and support contracts.
- What free tools do well, sometimes better for learning: a parametric made-to-measure workflow where changing a measurement redraws the pattern (Seamly2D, Valentina, FreeSewing, GarmentCode); formulas that show construction logic; and zero cost on every OS.
- deepnest-next is good enough to estimate fabric use for a home or small-studio project, or to lay pieces out for a laser or plotter. It is **not** a substitute for Diamino in a production marker, mainly because of the missing textile constraints. The quality claim is an inference: no head-to-head benchmark was found.
- Blender is a good free platform for learning 3D cloth concepts and for presentation renders. Making it a CLO3D-like "virtual fitting" tool needs paid add-ons and a lot of skill. Expect a much steeper learning curve and less accurate fabric behaviour than CLO3D.

### Gaps
- No published benchmark compares deepnest-next, SVGnest or Seamly2D layout efficiency with Diamino on real garment markers.
- No up-to-date, independent (non-vendor) 2025–2026 review was found comparing Seamly2D or Valentina directly with Modaris feature by feature.
- Whether deepnest-next has any grain-direction or fixed-orientation option beyond the rotation count was not verified.

## Q4. Which combination makes the best free "home toolkit" for a fashion student who uses Modaris at university?

### Takeaway
The best free 2026 toolkit is: **Seamly2D** for parametric drafting, measurement tables, multisize and DXF-AAMA export (Italian UI and manual available); **Inkscape** for finishing, overlaying sizes and tiling for home printing; **deepnest-next** for rough marker and consumption experiments; **Blender 5.2 LTS** for 3D, optionally with the paid Garment Tool add-on ($54); and **FreeSewing** for instant made-to-measure base blocks. Programmers can add **ezdxf/astm-parser** for automation. Valentina is an option only as the free legacy 0.7.53 or as a paid subscription. Modaris stays the reference for grading, AAMA hand-in and markers at university.

### Cited Findings
- Seamly2D: free (GPLv3+), weekly 2026 releases, Windows/macOS/Linux including ARM64, Italian manual and translation, multisize and custom-fit measurement files, seam allowance, notches, layout, DXF/AAMA export. — [Seamly2D GitHub](https://github.com/FashionFreedom/Seamly2D); [Seamly2D releases](https://github.com/FashionFreedom/Seamly2D/releases); [Seamly wiki Manuale Utenti (it)](https://wiki.seamly.io/wiki/User_Manual/it)
- The Seamly developers' own recommended workflow for overlaying multisize output is to export SVG per size and combine them in Inkscape. — [FashionFreedom Discussion #1199](https://github.com/orgs/FashionFreedom/discussions/1199); Italian video on the same workflow: [Sviluppo taglie con Seamly2d e Inkscape](https://www.youtube.com/watch?v=mrBydsWTt9Y)
- Valentina 1.x requires a subscription, and 0.7.53 is the last free build. — [Valentina 1.0.0 page](https://smart-pattern.com.ua/en/private/valentina/version/1.0.0/); [Valentina 0.7.53](https://smart-pattern.com.ua/en/valentina/version/0.7.53/)
- FreeSewing: MIT, v4.10.2 (Sep 2026), PDF/SVG export, made-to-measure from the user's own measurements. — [npm @freesewing/core](https://registry.npmjs.org/@freesewing/core); [FreeSewing docs](https://freesewing.eu/docs/about/site/draft/)
- deepnest-next: MIT, signed Windows/macOS/Linux builds (v1.5.6, May 2025), SVG with DXF via conversion. — [deepnest-next](https://github.com/deepnest-next/deepnest); [deepnest-next releases](https://github.com/deepnest-next/deepnest/releases)
- Blender 5.2 LTS (Jul 2026, supported to Jul 2028). Garment Tool costs $54. A free "Seams to Sewing Pattern" add-on flattens 3D models into patterns. — [Blender 5.2](https://www.blender.org/download/releases/5-2/); [Garment Tool](https://bartoszstyperek.gumroad.com/l/GarmentTool?ref=311); [Thomas Kole s2s](https://thomaskole.nl/s2s/)
- ezdxf 1.4.4 (May 2026) and astm-parser are available for scripting DXF/AAMA/ASTM work. — [PyPI ezdxf](https://pypi.org/project/ezdxf/); [astm-parser](https://github.com/ksons/astm-parser)
- Low-cost commercial complements: Lekala (about $4 per made-to-measure pattern), Bootstrap Fashion (royalty-free made-to-measure), Wild Ginger Wild Things! (free, accessories only), Tailornova (paid, but exports DXF-AAMA and has 3D previews). — [Lekala](https://www.lekala.co/); [PatternReview: Bootstrap Fashion](https://sewing.patternreview.com/SewingDiscussions/topic/87603); [Wild Ginger Wild Things!](https://www.wildginger.com/products/wildthings.htm); [Capterra: Tailornova](https://www.capterra.com/p/179815/Tailornova/)

### Inferences
- **Suggested toolkit, in order of priority for a non-expert:**
  1. **Seamly2D + SeamlyMe** (core CAD): practise drafting (basi/cartamodelli) parametrically, build measurement tables (tabelle taglie), multisize, seam allowance, notches. Export SVG/PDF for home printing and DXF-AAMA for Modaris tests.
  2. **Inkscape** (free): clean up, overlay sizes, add labels, tile prints, prepare portfolio drawings.
  3. **FreeSewing** (web, free): instant made-to-measure blocks to compare against her own drafts. Good for fitting studies.
  4. **deepnest-next** (free): rough "piazzamento" (marker) experiments and fabric-consumption estimates from SVG. Results are only indicative.
  5. **Blender 5.2 LTS** (free) + optional **Garment Tool** ($54): 3D draping and visualisation for a portfolio. Expect a steep learning curve. If her university provides CLO3D or Modaris 3D, those are much better for fitting.
  6. Optional, for the technically curious: **ezdxf / astm-parser / GarmentCode** for automation experiments, such as inspecting Modaris AAMA exports or generating patterns from code.
- **Workflow advice**: use home tools to learn and draft. Keep graded masters and markers in Modaris. When moving files home → university, send single-size DXF-AAMA and check notches, grain, seam allowance and units in Modaris. Grading should be done again in Modaris. Moving files university → home is not well supported by free software.
- Italian-language support is strongest for Seamly2D (manual, translation, YouTube). It is weak or unverified for FreeSewing, Blender add-ons and nesting tools, though Blender itself has an Italian UI (general knowledge, not verified here).
- Ease of learning, inferred from tool type and docs: FreeSewing is easiest (web forms). Seamly2D is moderate; its point/formula logic is familiar to a Modaris user, but the UI is dated. deepnest-next is easy. Inkscape is moderate. Blender cloth is hard. GarmentCode and Sewformer need programming.

### Gaps
- No survey or forum thread was found where Italian fashion students describe this exact home + Modaris workflow.
- Whether Lectra offers free or discounted student home licences of Modaris was not researched here (it belongs to the Lectra-focused research stream).
- Current Valentina subscription cost, which matters if the paid 1.x is recommended for its better AAMA/ASTM, is unknown.
