# Dirtywave M8 via MIDI

- Tasti = note sul canale **CONTROL MAP CHAN** (Project > MIDI > Settings, di serie 10).
  Note On = giù, Note Off = su. 0 play · 1 shift · 2 edit · 3 option · 4 sinistra · 5 destra · 6 su · 7 giù.
- Note 12-19 = mute tracce 1-8, 20-27 = solo 1-8 (stessa fonte, da provare).
- I CC sullo stesso canale si assegnano a qualunque parametro in Project > MIDI Mapping (fino a 128).
- SONG ROW CUE CHANNEL: note che mettono in coda le righe della song.
- USB MIDI fa le stesse cose del MIDI TRS (manuale 6.0, «USB Features»). Niente bluetooth di serie.

Fonti: manuale M8 6.0.0 (p. 44, 65); handeyeco.github.io/tech-blog/m8-basic-midi (mappa note, non nel manuale).
